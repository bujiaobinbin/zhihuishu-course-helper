# 知到课程连续学习助手

适用于知到「新形态课程」网页（`ai-smart-course-student-pro.zhihuishu.com`）的 Chrome / Edge 本地扩展。无需编程、无需配置课程编号。同样页面结构的其他课程也可以使用；其他知到平台页面不支持。

## 下载与安装（约两分钟）

1. 点击本仓库绿色 **Code → Download ZIP**，解压到一个长期保留的文件夹。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启 **开发者模式**，点击 **加载已解压的扩展**。
4. 选择解压文件夹中的 **extension** 文件夹（里面有 `manifest.json` 和 `helper.js`）。不要选择整个仓库或 ZIP 文件。
5. 登录你自己的知到账号，打开课程学习页并刷新。右下角出现助手后，点击 **开始／继续**。

使用期间保留扩展文件夹，保持浏览器和课程标签页开启，电脑不要休眠。无需开启 Codex 或终端。

## 功能与控制

- 根据当前地址识别课程，运行状态按课程分别保存；首次安装需要主动开始。
- 页面刷新后恢复已开启的助手；点击「暂停」后刷新也不会自行启动。
- 按网站完成标记跳过已完成的必学资源。知识点完成后打开总目录，寻找尚未完成的知识点。
- 视频暂停时尝试恢复，播放保持 1.5 倍速。浏览器禁止自动播放时需要本人点击播放。
- 视频真实结束后等待网站同步；必要时刷新一次、正常重播一次。网站仍未确认完成时暂停，避免无限刷新重播。
- 非视频资源按网站要求自行阅读或作答；完成标记出现后继续。登录、验证码和弹窗需要本人处理。
- **暂停**：停止自动导航和恢复，当前视频可能继续播放。
- **停止**：停止助手并隐藏面板；刷新页面可再次显示面板，默认不运行。

只处理必学资源。目录稳定加载并不保证网站没有隐藏或分页内容；目录提示 100% 不代表作业、考试或全部课程任务完成。不同课程页面结构可能不同，目前通用化版本仅做本地逻辑验证，尚未在朋友账号实测。

## 更新

本地扩展不会自动从 GitHub 更新。下载新版后，用新版 `extension` 中的文件替换原文件，在扩展管理页点击该扩展的 **重新加载**，再刷新课程页。原文件夹路径保持不变。

## 隐私

不收集或上传账号、Cookie、学习记录；没有外部网络请求或额外浏览器权限。助手仅读取课程页面，运行与恢复状态保存在该网站的本地浏览器存储。请勿在公开 Issue 中上传个人账号、完整课程地址、Cookie 或未遮挡的截图。

## 开发与验证

安装 Node.js 后运行 `node --test tests/*.test.cjs`。源码无需构建；可直接加载 `extension`。

本项目使用 MIT 许可证。尊重课程平台规则，学习记录由网站正常播放和交互产生。
